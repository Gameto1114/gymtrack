Nombre del Proyecto:
GymTrack

Descripción del Problema:
Muchas personas desean llevar una rutina de entrenamiento organizada, pero no cuentan con una herramienta sencilla para visualizar ejercicios y mantener la motivación. GymTrack busca ofrecer una interfaz moderna donde los usuarios puedan conocer diferentes rutinas de entrenamiento y comenzar un estilo de vida saludable.

Tecnologías Utilizadas:
* React
* Vite
* JavaScript
* JSX
* CSS
* npm
